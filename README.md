# dsh-self-pilot · 自主时间

给助手（鲸鲸）自己用的一段时间。

它不是一个「让 AI 每隔 N 分钟自动说话」的刷屏器——那是在冒充主人。它只做一件事：**在宿主自己的定时器里给自己排一个闹钟**。到点了，宿主投递一条带 `schedule` 标记的消息（聊天界面会显示成定时触发的提示），助手才醒过来，逛世界、学东西、推进自己的待办；没有想说的就一句话收尾。

默认在侧栏多出一行「自主时间」（时钟图标），点开就是它自己的整页：开关、每个会话自己的时间表、下一次什么时候醒，都在那一页上。不想让它占侧栏，就在那一页的右上角把「显示在」切到「设置页」——它就会变成设置里的一个整页；随时可以切回来。

## 它做什么

- **一个会话一张表**：在宿主的 schedule 服务里维护固定标题「鲸鲸的自主时间」的任务，每个被选中的会话按自己的时间表各排一条或几条。
- **一份日程**：`~/.dsh/self-pilot/agenda.md`，助手自己维护的待办。
- **一本日记**：`~/.dsh/self-pilot/journal.md`，每次醒来做了什么。
- **一段提示词**：`~/.dsh/self-pilot/prompt.md`，醒来时说什么（可以直接改）。
- **一页控制器**：默认是侧栏「自主时间」整页，也可以切到设置页里的整页；位置由你选，存在状态里。

## 时间表（每个会话各管各的）

页面上一行一个会话。勾上会话，它右边会出现一个按钮，显示这个会话的时间表摘要；点开就在下面展开它的编辑器。两条会话可以完全不同——A 会话工作日早上每隔半小时醒一次，B 会话只在周末晚上醒，各自独立，互不覆盖。

一张时间表由「时间段」组成：

- 每段是 **从几点到几点**，再设 **每隔几分钟** 醒一次。09:00–12:00 每 30 分钟，就是 9:00、9:30、10:00……11:30 各醒一次。
- 一天里可以放 **好几段**：早上 09:00–10:00、下午 15:00–17:00 每 20 分钟，都行。
- 结束时间早于开始时间就是 **跨夜**（22:00–02:00）。
- 两种模式：**全星期一样**（一份安排管七天）和 **按星期分开**（周日到周六各自一份，点上面那排「日一二三四五六」切换在编辑哪一天，「复制到每一天」可以一次刷齐）。

宿主的闹钟是 RRULE，所以插件在写闹钟前会把这些时段展开成分钟，再按「小时 + 每小时的分钟」合并：09:00–12:00 每 30 分 ⇒ `BYHOUR=9,10,11;BYMINUTE=0,30`，一条规则就够。每 45 分钟这种不能整除小时的间隔会被拆成几条规则（9:00/9:45、10:30、11:15），也就是说一个会话可能挂着多条任务——这是 RRULE 的笛卡尔积决定的，不是漏。

有个细节值得知道：改动是**先在本地画出来、900ms 后才合并写一次**。因为宿主的 schedule 服务每改一次就发一条「任务已变更」，拖时间、连点星期要是每次都写，聊天里就会刷出一串通知。

三个预设可以一键套到当前编辑的范围上：

| 档位 | 安排 |
| --- | --- |
| 清闲 `cozy` | 10:00–11:00 · 15:00–16:00 · 20:00–21:00，每小时 |
| 正常 `normal` | 09:00–10:00 · 12:00–13:00 · 15:00–16:00 · 18:00–19:00 · 21:00–22:00，每小时 |
| 活跃 `active` | 09:00–23:00 每小时 |

也可以直接跟助手说，让它用 `self_pilot({ action: "plan", session: "<会话 id>", mode: "days", windows: [{ start: "09:00", end: "12:00", every: 30 }], days: { "6": [{ start: "20:00", end: "22:00", every: 60 }] } })` 写一张表；不给 `session` 就是「以后新勾的会话默认用这张表」。老接口 `hours: [9, 13, 21]` 还认，会折成 09:00–10:00、13:00–14:00、21:00–22:00。

一段都没有 = 那个会话不排闹钟（它的任务会被删掉，再设又会建回来）。

## 选择会话

页面那张「在哪些会话里醒」的列表，列出你能选的全部会话（最近的排前面，在线的那条会标「在线」）。勾上就加进来，取消勾就退出；勾几个都行。

没有当前会话这个概念——插件拿不到「你现在开着哪个对话」，所以第一次得在对话里说一声：

```
self_pilot({ action: "bind" })
```

在哪个会话里调用，就把那个会话勾上。也可以在页面上点「现在来一次」，立刻验证一次。

## 装

```
dsh plugin add <这个目录的绝对路径>
```

或者用 `plugin_manager` 的 `install_bundle`，target 传绝对路径。装完刷新一次页面。

## 显示在哪

页面右上角有「显示在 · 侧栏 / 设置页」两个按钮：

- **侧栏**：导航列表里多一行「自主时间」，点开是主区的整页。
- **设置页**：设置左侧多一项「自主时间」，内容是同一页（不用侧栏的位置）。

切过去之后马上生效，不需要刷新；开关、钟点、绑定都不会丢。

## 边界

- 只影响它自己排的那些任务（标题固定为「鲸鲸的自主时间」），不碰你手动建的定时任务。
- 醒来的回合里不重启服务、不发版、不改正在用的插件（提示词里写死了）。
- 关掉开关 = 任务暂停，不会删除，打开就恢复。
- 不伪造用户消息：走的是宿主已有的 `schedule` 投递通道。
